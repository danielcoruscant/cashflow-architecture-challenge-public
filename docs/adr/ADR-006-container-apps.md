# ADR-006 - Execução em Azure Container Apps

## Status

Aceito

## Contexto

A carga estimada é relativamente baixa.

## Decisão

Utilizar Azure Container Apps.

## Consequências

### Positivas

- baixo custo operacional
- autoscaling
- simplicidade operacional

### Negativas

- menor flexibilidade que AKS

## Alternativas

AKS

Rejeitado por aumentar complexidade sem benefício relevante.
